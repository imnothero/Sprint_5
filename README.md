# Sprint_5

Автоматизированные тесты для Stellar Burgers

Описание

Этот проект содержит UI-тесты для веб-приложения [Stellar Burgers](https://stellarburgers.nomoreparties.site/).  
Тестируется основной пользовательский функционал:

- вход в аккаунт разными способами;
- регистрация нового пользователя;
- переходы между страницами;
- выход из личного кабинета.
